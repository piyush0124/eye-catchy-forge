# Corporate Event Sections Redesign

## Goal
Refresh Past Editions, Event Glimpses, and Partners in the selected Corporate Minimalist direction while preserving the website’s existing dark indigo–violet theme and typography.

## Changes
- Recompose Past Editions as a cleaner editorial archive with stronger featured imagery, year filters, and a compact scannable event list for all records.
- Rebuild Event Glimpses as an asymmetric image mosaic using all 20 existing event photographs, with subtle captions and varied visual scale.
- Redesign Partners as a static, spacious sponsor wall with distinctive typographic marks and restrained interactive polish.
- Add staggered entrance, image zoom, caption, timeline, and light-sweep effects with reduced-motion support.
- Keep upcoming conferences, all content, filters, and show-more behavior intact.

## Technical Details
- Update the existing section components and global animation utilities only.
- Reuse current local event assets; no new content or backend changes.
- Verify desktop and mobile layouts, interaction behavior, and the project build.
